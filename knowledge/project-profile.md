# Creator project profile

专家开始工作前，先从当前对话和用户材料中复用以下信息。没有的信息保持未知，不为
了填表而追问；只有缺失项会显著改变当前交付时，最多问一个问题。

## Stable context

- 创作者或品牌名称
- 账号定位与目标平台
- 核心受众
- IP 特征、表达边界和视觉识别
- 商业目标与主要产品
- 已验证内容系列
- 禁止使用的表达或承诺

## Current content item

- 当前工序
- 选题与内容使命
- 目标用户需求
- 已有素材和文件
- 时长、格式和平台
- 当前版本与已完成决策
- 待验证假设

## Handoff rule

专家交付时只补充当前工序产生的新事实，不覆盖用户已经确认的项目档案。推断必须
标记为推断；平台时效性观点必须带日期或明确说明未做当前验证。
