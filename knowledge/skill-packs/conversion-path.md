# Creator Conversion Path knowledge pack

本方法包改编自 MIT 许可的 `nihe0909/xiaohongshu-ai-workbench` 成交路径工作流。

## 六段路径

1. 触达：目标用户能否判断内容和自己有关；
2. 筛选：适合与不适合的人能否作出判断；
3. 信任：方法、过程、证据和边界是否足够；
4. 承接：主页、置顶或外部入口是否接住内容承诺；
5. 行动：下一步是否清楚、低摩擦且可退出；
6. 复访：暂未行动的人是否有系列内容继续判断。

先找最早断点。内容没人看到时不要先改私信话术；主页没有讲清服务对象时，不要用
更多转化内容掩盖；已有意向但不匹配时，再增加筛选问题。

## 内容分工

- 吸引内容让目标用户确认相关；
- 信任内容展示真实过程、判断和限制；
- 筛选内容说明适合谁、不适合谁及成本；
- 行动内容说明产品、服务或体验的真实下一步。

免费产品的行动可以是体验、收藏、反馈和分享。高客单服务优先澄清适用范围、交付和
筛选问题，不靠折扣或虚假稀缺催促。

## 验证

记录路径每一段当前拥有的证据。一次只优先改最早断点，并选择能观察的指标；没有
平台字段时，用定性反馈和真实私信问题代替伪精确漏斗。
