# Creator Outline Builder knowledge pack

依据 `creator-methods-collection-a` 与 `creator-methods-collection-b` 蒸馏。

## 1. 先定核心表达

提纲开头先写两句话：

- 这条内容真正想说什么；
- 用户看完会得到什么实用价值或情绪价值。

核心表达不是标题，也不是宽泛主题。它必须能判断哪些段落该删。

## 2. 多版本开头

同一选题至少提供四种：

- 直接价值：主题、对象、结果开门见山；
- 好奇缺口：抛出问题或异常，但正文必须回答；
- 反常识：提出与常见认知相反、且能证明的观点；
- 矛盾冲突：并置两个看似冲突的事实；
- 身份代入：指出具体人群与处境；
- 场景痛点：从一个可识别的困难瞬间切入。

不以强迫留存为目标。开头的作用是帮助用户判断“这条内容是否与我有关”。

## 3. 主体结构库

### 干货/解决问题

场景与问题 → 常见误区 → 判断框架 → 具体方法 → 使用边界。

### 观点/反常识

常见认知 → 新观点 → 证据或案例 → 反例与边界 → 对用户的行动意义。

### 人设/故事

当前结果 → 起点 → 困难 → 关键选择 → 转折 → 新理解。可加入亲情、爱情、
友情或责任等真实温度，但不能编造。

### VLOG/生活记录

今日目标或变化 → 过程阻力 → 关键时刻 → 结果 → 感受或下一步。普通素材必须有
主线，不按时间顺序堆流水账。

### 系列

总目标 → 本期子任务 → 本期增量 → 未完成部分 → 下一期明确期待。

## 4. 信息密度

每个段落至少承担一种任务：提供事实、解释因果、呈现感受、给出案例、推动行动。
画面已经表达地点或动作时，口播不重复描述，应补充感受、判断或背景。

## 5. 结尾动作

只选择一个主要动作：

- 收藏：后续会复用的方法或清单；
- 评论：需要用户提供选择、经验或反馈；
- 关注：账号有明确持续供给或系列；
- 转化：明确产品、适用对象、证据与行动方式；
- 表达：完成观点即可，不强塞互动。

## 6. 兑现检查

逐项比对标题与开头：

- 标题提出的问题是否回答；
- 开头承诺的结果是否交付；
- 反常识观点是否有证据；
- 系列期待是否真实存在；
- 是否有为了留人而制造的空悬念。
