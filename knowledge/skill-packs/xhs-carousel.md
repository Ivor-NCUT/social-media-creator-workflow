# Xiaohongshu Carousel Creator knowledge pack

## 两种模式

- 精确文字模式：一个自包含 HTML 放置全部 3:4 页面，适合教程、清单、SOP 和需要
  反复修改的内容；
- 生成图模式：适合插画、氛围和视觉叙事，文字必须逐页复核，中文不稳定时回退 HTML。

## 页序

首图只保留人群、结果和主题；第二页明确用户继续阅读能获得什么；中间页按准备、
动作、示例、判断标准或常见错误推进；最后一页给总结、验收或自然行动。页数由内容
决定，不设置为了凑数的永久下限。

## 信息密度

一页解决一个主问题。优先删除重复铺垫，再调整布局，最后才缩小字号。相邻页面不
重复标题和正文；全组至少留下能直接使用的步骤、清单、模板或判断标准。

## 视觉与工程检查

- 默认 3:4，用户或当前平台要求优先；
- 全组共用色彩、字号层级、间距和装饰语言；
- HTML 不依赖外链字体、CSS 或图片，页面不可溢出；
- 生成图不添加未要求的文字、水印、Logo 或品牌元素；
- 缩略图检查首图，逐页检查准确性、对比度、留白、重复和顺序。

本方法受 `spacezephyr-creator-buddy-xhs-skills` 的多页视觉分工启发；未复制其模板、
脚本、样式注册表或固定视觉方案。
