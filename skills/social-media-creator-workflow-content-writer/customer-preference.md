# Customer preference

### H-001 核心定位的高信号经历不能被流畅主线吞掉

- 状态：validated
- 置信度：high
- 适用场景：公众号人物长文、候选人推荐信、职业人物故事
- 不适用场景：只要求单段经历、短摘要或严格限定素材范围
- 正向证据：用户亲自修改完整推荐信，并明确指出遗漏的 AI Native 公司经历必须补回
- 反向证据：无
- 可能误判：不是要求把所有简历逐项写进文章，弱相关经历仍可省略
- 对生成的影响：动笔前制作高信号经历覆盖表；直接证明文章主旨或目标岗位的经历标为必写
- 最近验证日期：2026-08-02

### H-002 前沿工具能力必须落到真实生产证据链

- 状态：validated
- 置信度：high
- 适用场景：AI 人才推荐、技术型人物故事、AI Native 公司经历
- 不适用场景：纯工具教程或产品功能清单
- 正向证据：用户要求强调 Claude Code、Codex 等 Agent 工具在真实增长工作中的落地
- 反向证据：用户明确不满足于只列工具名
- 可能误判：不能为了完整证据链编造团队影响或业务结果
- 对生成的影响：优先写“工具 → 真实业务流程 → 团队或用户 → 结果”
- 最近验证日期：2026-08-02
