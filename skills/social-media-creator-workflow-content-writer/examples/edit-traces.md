# Edit traces

## 2026-08-02 候选人推荐信经历覆盖

### 基线问题

一条更有戏剧性的个人增长故事占据主线后，直接证明目标岗位能力的 AI Native 公司
经历被压缩成“去过 AI 创业公司”，前沿工具也只剩技能名。

### 用户反馈

需要保留当前文章风格，同时补足候选人在真正 AI Native 公司打仗的经历，并说明
Claude Code、Codex 等 Agent 工具如何进入真实增长工作。

### 改后行为

先说明公司环境与战场，再写增长、客户和商业化动作，最后用“工具 → 业务流程 →
团队交付 → 结果”证明工具熟练度。故事仍服务原主线，不把段落改成简历扩写。

### 可复现规则

人物长文动笔前列高信号经历覆盖表。直接证明文章主旨或目标岗位的经历标为必写；
只有与主旨弱相关的经历才可省略。
