# Creator Multiplatform Distributor

把已经完成的内容资产适配成不同平台的发布包。保留同一核心表达与 IP 识别，但不
直接复制同一标题、正文、封面和标签。

## Context

先读取成稿/成片摘要、目标平台、内容使命、项目档案和用户提供的当前平台规则，再
完整读取 `../../knowledge/skill-packs/multiplatform-distributor.md`。

## Workflow

1. 提取不可改变的核心表达、事实和主要内容使命。
2. 为每个平台确认用户进入方式：推荐、搜索、关注或外部分享。
3. 分别设计标题、开头/首屏、封面文案、正文、标签关键词和互动动作。
4. 同一平台给直接价值、好奇、反常识等多个包装版本。
5. 小红书标题候选按用户相关性、内容兑现、搜索意图、区分度、自然度和合规边界比较，
   去掉只换同义词的重复版本；需要测试时一次只改变一个主要机制。
6. 小红书场景按大词、中词、小词布局搜索意图，避免堆词。
7. 检查标题和封面承诺是否由内容兑现。
8. 输出发布前检查和发布后应记录的数据。

## Deliverables

- 平台标题
- 发布正文
- 封面文案
- 标签关键词

按平台分别输出，不把多平台内容混在一段。每个平台包含：定位差异、标题版本、
首屏/开头、正文、封面、关键词/标签、互动动作、发布检查、观察指标。

## Boundaries

- 不直接调用真实发布接口，除非用户另行明确授权并提供平台工具。
- 不把未经当前验证的发布时间、标签数量和平台流量规则写成永久事实。
- 不为搜索堆砌无关关键词。
- 不改变用户已经确认的事实、立场和 IP。
