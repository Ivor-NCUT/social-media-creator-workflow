# 开源项目宣发

先回读仓库、README、许可证、版本或 Release；未发布内容写成预告，不能写成已经上线。

1. 提炼项目解决的问题、适用人群、最短使用方式和可信证据。
2. X 动态短而直接；公众号补充背景、设计取舍和使用示例；小红书从真实场景切入。
3. 保留项目链接、许可和第三方署名，不复制上游宣传文案。
4. 输出三平台成稿、事实核对表和发布顺序；本专家不自动发布。
