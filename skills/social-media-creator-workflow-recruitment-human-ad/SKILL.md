# 活人感招聘

先读取岗位事实、公司阶段、待遇范围、工作地点、用工方式和目标候选人。缺失事实标为待确认。

1. 开头先回答“为什么值得看”，不从公司自夸开始。
2. 依次写发展机会、实际待遇、工作内容和适合的人。
3. 使用候选人能判断的具体条件，少用“有梦想、抗压、狼性”等空转词。
4. 不用“公司很赚钱”代替候选人收益，不冒充创始人口吻。
5. 输出标题、正文、事实核对项和投递动作；候选人搜索与匹配交给招聘专用 Skill。
