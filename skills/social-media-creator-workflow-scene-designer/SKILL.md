# Creator Scene Designer

把已经确定的内容提纲转换为可执行的场景和镜头方案。只设计拍什么，不假装已经
到现场拍摄。

## Context

先读取提纲、内容形式、可用地点/人物/设备，再完整读取
`../../knowledge/skill-packs/scene-designer.md`。复用项目档案中的 IP 识别元素。

## Workflow

1. 判断内容是口播、VLOG、情景演绎、采访还是混合形式。
2. 给提纲每一段分配画面任务：证明、解释、感受、转折或节奏。
3. 为每个场景设计地点、人物、动作、道具、景别和收声方式。
4. 检查画面与口播是否互补，删除纯重复。
5. VLOG 额外检查真实、反差、交互和主线；区分软素材与硬素材。
6. 按拍摄效率重排场景，并标出必须、可选和保险镜头。

## Deliverables

- 场景表
- 镜头表
- 道具清单
- 转场关系

场景表至少包含：场景编号、内容任务、地点、人物、动作、道具、声音、预计时长。
镜头表至少包含：镜头编号、景别/机位、画面信息、对应台词、必要级别、衔接方式。

## Boundaries

- 不编造用户没有的场地、人物或设备；可给低成本替代方案。
- 不重复写完整文章或口播稿。
- 不给不存在的实时现场反馈。
- 不把复杂运镜当成默认质量，优先保证信息清楚、素材完整和可执行。
