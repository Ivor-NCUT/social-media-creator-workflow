# Xiaohongshu cover presets

以下 18 种预设风格改编自 Vivi 的
[`xhs-cover-skill`](https://github.com/Vivixiao980/xhs-cover-skill)，用于选择生成方向，
不是固定模板。用户提供参考图或明确要求时，以用户输入覆盖预设。

| ID | 中文名 | 视觉方向 |
|---|---|---|
| `hand-drawn-border` | 手绘边框 | 黄色手绘描边，综艺活力感 |
| `outdoor-handwriting` | 户外手写 | 竖排毛笔黄字，清新自由感 |
| `neon-contrast` | 霓虹撞色 | 荧光粉绿撞色，Y2K 潮流感 |
| `multi-layer-layout` | 多层排版 | 黑橙混排，杂志编辑感 |
| `study-room-intellectual` | 书房知性 | 奶油色手写字，温暖知性感 |
| `professional-woman` | 职场女性 | 奶黄大字与红色虚线，清晰有力量 |
| `sticker-energy` | 贴纸活力 | 人物抠图贴纸，闪电与星星装饰 |
| `dashed-decoration` | 虚线装饰 | 白色主字、橙色副标与虚线半圆 |
| `background-big-text` | 背景大字 | 超大橙字作为背景，人物置于前景 |
| `thinking-question` | 思考提问 | 蓝灰毛笔字与问号构图 |
| `split-screen-tags` | 分屏标签 | 上图下色块，黄蓝标签排版 |
| `cozy-home` | 温馨居家 | 黄白渐变字与椭圆高亮 |
| `workplace-big-text` | 职场大字 | 白色超大字叠人物，强冲击力 |
| `dark-glow` | 深色发光 | 深色背景与黄色发光文字 |
| `home-motivation` | 居家励志 | 亮黄大字与开放姿势场景 |
| `yellow-pink-banner` | 黄粉横幅 | 顶部黄字与底部粉色横幅 |
| `pink-yellow-playful` | 粉黄俏皮 | 波浪英文感与手写中文气质，不添加随机英文 |
| `professional-clean` | 专业简洁 | 白字简洁排版与现代办公场景 |

所有预设都遵循：

- 只使用用户确认的主标题和副标题；
- 人物脸部身份自然一致；
- 优先保证手机信息流中的文字清晰度；
- 不添加随机英文、水印或未要求的品牌标识。
