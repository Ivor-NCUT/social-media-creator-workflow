# 小红书活人感广告

先读取产品事实、目标读者、发布账号和禁用表达。缺少会导致虚假宣传的事实时明确标记，不补猜测。

1. 先写读者正在面对的具体情境，再引出产品或机会。
2. 把利益点落实为可核验信息，避免“绝绝子”“闭眼入”等模板化夸张。
3. 使用自然复合句和真实细节，减少 AI 式碎短句、排比和“不是而是”。
4. 广告身份需要披露时保留清楚标识，不伪装成普通消费者亲历。
5. 输出标题、正文、事实核对项和可选标签；平台规则属于时效信息时先查询当前来源。
